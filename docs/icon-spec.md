# onchato - icon: a task for Claude Code

> Done: the full set is in `assets/icon/`, generated by `scripts/build-icons.mjs`
> (`make icons`). This file stays as the specification of the mark.

## Goal
Generate the full set of onchato icon files (P2P E2EE chat, whisper mode) from a
single SVG source. Zero hand drawing beyond the given geometry. Everything must be
reproducible by a script.

## Mark
Two vertical strokes. The left one broken (the speaker's mouth). The right one with
a single inward bend (the listener's ear). Nothing more: no waves, dots,
shadows, gradients, or text in the mark.

Master geometry, 100x100 space, stroke-linecap round, fill none:

    stroke-width 8
    M36 14 V44                         left top
    M36 62 V92                         left bottom
    M64 14 V38 C52 44 52 62 64 68 V92  right with the ear

Small variant (for 16 and 32 px), the same 100x100 space:

    stroke-width 10
    M36 12 V40
    M36 66 V94
    M64 12 V36 C50 42 50 64 64 70 V94

Rule: in a 16 px render the gap must be >= 3 px, the stroke >= 1.5 px.
Do not scale the master to 16 px, use the small variant.

## Script
    scripts/build-icons.mjs (sharp)
    - source: assets/icon/src/*.svg, nothing is edited by hand
    - rasterisation: rsvg-convert or sharp; not ImageMagick with default
      antialiasing
    - PNG: sRGB, 8 bit, no metadata, optimised (oxipng; not
      pngquant, because it loses colour; lossless only)
    - ico: png-to-ico or icotool
    - the `make icons` command recreates everything from scratch

## Acceptance criteria
    1. Render of favicon-16.png: the gap in the left stroke is visible, the ear
       does not merge with the vertical. Check at x8 magnification and add
       control PNGs to assets/icon/preview/.
    2. tile-dark 512 vs 48: mark proportions identical within 1 px.
    3. Maskable: the mark entirely inside a circle of 80% of the tile's diameter.
    4. No file contains gradients, filters, embedded fonts,
       or <text> elements.
    5. All SVGs pass svgo without geometry changes; the viewBox
       starts at 0 0.
    6. Generate preview.html in assets/icon/preview/ showing all
       files side by side on a light and a dark background.

## What not to do
    - do not add waves, dots or text to the mark
    - do not change the proportions of the gap or the depth of the ear
    - do not use pure #000000 (banding on OLED with background animation)
    - do not generate icons from a font or from emoji
